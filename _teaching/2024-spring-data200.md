An introductory data science course for students with any level of programming experience. I redesigned the projects and modules so that beginners are not overwhelmed and experienced students are still challenged. Students finish the course able to manage real datasets in Python, track their work in Git, and write up results in LaTeX.

**Taught:** Spring 2024, Spring 2025, Spring 2026. 

## Tools students learn

- **Python** in reproducible **Anaconda** environments, using **PyCharm Professional** (free through JMU student access)
- **Git and GitHub** for version control and submitting work
- **LaTeX** (with Overleaf) for reports
- pandas, NumPy, and Matplotlib for data handling and visualization

## Course structure

<!-- EDIT: replace this list with your actual units and link each to its folder in the course repository. -->

1. **Setting up a reproducible workflow:** Anaconda environments, PyCharm, Git and GitHub
2. **Python for data:** core syntax, functions, and working with files
3. **Data management:** cleaning, merging, and reshaping data; working with large datasets and databases
4. **Visualization and statistical analysis:** exploring data and communicating results
5. **Data science and personal finance:** projects applying data methods to financial literacy questions
6. **Final project:** an independent analysis of a real dataset, written up in LaTeX and published on GitHub
