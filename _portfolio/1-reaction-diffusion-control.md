Simulation and analysis code behind the group's work on localized control of spatiotemporal chaos.

- **Simulation (C++):** explicit Euler and fourth-order Runge–Kutta integrators for the Gray–Scott model in one and two dimensions, with localized time-delayed feedback, parameter perturbations, and field-induced patterning
- **Analysis (Python):** Fourier analysis and tools for detecting periodic structures in space-time data
- **Visualization:** space-time plots and animations
